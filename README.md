# Koushik Jamboju — Creative Portfolio

A responsive, single-page portfolio website for GitHub Pages. Built with plain HTML and CSS, so no build tools or coding setup are required.

## Files
- `index.html` — the full website.
- `assets/work/` — place portfolio images or other project assets here later.

## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new **public** repository named `koushik-portfolio` (or another name you prefer).
2. On the new repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `README.md`, and the `assets` folder from this project. Keep `index.html` in the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for deployment, then open the URL shown in the Pages settings. A project site usually has a URL like `https://YOUR-USERNAME.github.io/koushik-portfolio/`.

GitHub Pages is public. Do not upload private documents, passwords, client files you don't have permission to publish, or sensitive personal information.

## Add work later
1. In your repository, open `assets/work/` and upload an image or video thumbnail. For video files, it is usually better to upload the video to a platform you control and link to it, rather than making the website download a large file.
2. Open `index.html` and click the pencil icon to edit it.
3. Find the `<!-- WORK CARDS -->` area (or search for `PROJECTS COMING SOON`). Replace a placeholder card with a project title, description, and image.
4. Click **Commit changes**. GitHub Pages will publish the update after its deployment finishes.
